# 飞书多维表格 Schema 设计

本文件描述 `inventory_bot` 依赖的飞书多维表格（Bitable）结构。在启用机器人前，请先按以下说明在 Bitable 中创建这 7 张表。

## 创建步骤

1. 在飞书中新建一个多维表格，名称建议：**"备货管理 - YYYY"**。
2. 打开表格后，复制地址栏 URL 中 `base/` 后、`?table=` 前的一段字符串。这就是 `BITABLE_APP_TOKEN`，填入 `.env`。
3. 在机器人所在企业的开发者后台 https://open.feishu.cn/app 创建一个自建应用，开通 `bitable:app:readonly` 和 `bitable:app` 权限，获取 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`。
4. 将应用添加为多维表格的协作者（文档分享 → 添加机器人）。
5. 按下方 7 张表逐一创建 —— **表名和字段名必须和下面完全一致**（机器人通过表名找表、通过字段名映射数据）。

## 可视化建议

基于"决策日志"，建立以下视图（Bitable 的"视图"功能）：

1. **本周急单** — 筛选 `状态 = 🔴急单` 并按紧急度分数升序
2. **本周计划** — 筛选 `状态 = 🟡计划`
3. **死库存清单** — 筛选 `状态 = 🟤死库存`
4. **待审核** — 筛选 `决策 = 待审核`
5. **已下单** — 筛选 `决策 = 已下单`，按 SKU 分组

## 环境变量

在 `.env` 文件中填入：

```dotenv
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxxxx
BITABLE_APP_TOKEN=xxxxx
FEISHU_BOT_WEBHOOK=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx
FEISHU_BOT_SECRET=xxxxx   # 可选；启用签名校验时需要
```

## 字段名称变更

如果你想改 Bitable 中的字段名称，请同步修改：

- `inventory_bot/clients/bitable.py` 中顶部的各 `*_FIELDS` 映射字典

映射字典的左侧是 Bitable 中显示的列名，右侧是代码里的属性名 —— **永远只动左侧**。
